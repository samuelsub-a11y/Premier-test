# Révisions de droit

Site statique de révision pour étudiants en droit : fiches d'arrêts, quiz, flashcards à répétition espacée, méthodologie, ainsi qu'une page de présentation de cours particuliers.

- **Technologies** : HTML, CSS et JavaScript, sans serveur, sans base de données et sans dépendance.
- **Contenu** : entièrement dans le dossier `donnees/` (fichiers JSON).
- **Mode d'emploi** : voir [GUIDE.md](GUIDE.md) (ajouter une fiche, une question, mettre en ligne).
- **Contrôle des données** : ouvrir `verification.html`.

⚠️ Les contenus juridiques marqués « À VÉRIFIER » sont en cours de relecture.
